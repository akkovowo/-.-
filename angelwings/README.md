# angelwings — читаемая версия

- `angelwings_full.lua` — весь скрипт (~9,9 тыс. строк), готов к загрузке в gamesense. В начало добавлен блок из исходного загрузчика:
  он записывает ресурсы (картинка, trashtalk.txt, trashtalk2.txt) в папку `angelwings/` и задаёт `offline_http`.
- `antiaim.lua`, `visuals.lua`, `config_cloud.lua` — выжимки по разделам (кода из `angelwings_full.lua`, для чтения).
- `angelwings_rebuilt.luac` — пересобранный байт-код Lua 5.1 (для проверки, в gamesense не грузится).
- `tools/` — декомпилятор (Python) и проверка (`tools/validate`).

## Как получено
Исходник — байт-код Lua 5.1, развёрнутый в блоки `::pc_N::`. Он собран обратно в настоящий `.luac` и декомпилирован `unluac` с моими правками.
Шифрованные строки (адреса CDN) расшифрованы запуском оригинальных функций-дешифраторов.

## Проверка
Пересобранный байт-код и оригинал выполнялись в песочнице с заглушками API; журналы вызовов (819 тыс. строк) совпадают.
Для читаемого текста совпадение полное, кроме порядка вычисления операндов в сравнениях и артефактов заглушек.
В реальном gamesense не запускалось.

## Известные огрехи
Параметры функций называются `arg1..argN`, часть локальных — `vNN`; функции `encode/decode` конфигов и индикатор SHOT переписаны вручную по байт-коду.
