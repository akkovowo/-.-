# angelwings — читаемая версия

`angelwings_full.lua` — весь скрипт (≈9,7 тыс. строк). `antiaim.lua`, `visuals.lua`, `config_cloud.lua` — выжимки по разделам.

Как получено: исходник — байт-код Lua 5.1, развёрнутый в блоки `::pc_N::`. `tools/` собирает из него настоящий `.luac`
(`tr*.py`, `asm.py`, `locals.py`, `naming.py`, `build.py`) и прогоняет через `unluac` (с правками для явных регистров локальных).
Проверка: пересобранный байт-код и оригинал выполнялись с заглушками API — трассы вызовов совпали (расхождения только из-за заглушек).

Известные огрехи: ~60 мест, где `unluac` неверно оформил область видимости локальной (в основном в служебных функциях защиты);
параметры называются `arg1..argN`; часть локальных имеет имена `vNN`.
